POC pipeline/ documentation

How the Gradio demo turns a long educational video into one compilation: timestamped transcript, Ollama nomination, embedding rank, human keep-gate, then a single assembled export.

Overview End-to-end flow Modules Data contracts Assemble Files

1. Overview

The pipeline is text-first. Clips are found from the WhisperX transcript, not by scanning pixels. Models only nominate and rank. A human must keep 3–5 on-topic clips before ffmpeg runs. The shipped artifact is one Demo/YouTube file, not separate raw cuts.

utils.py

Shared I/O

Run folders, JSON/SRT writers, ffmpeg/ffprobe wrappers, even dimensions, font lookup, snap_to_segments, excerpt by time range. Constants: MAX_REVIEW=10, MIN_KEEP=3, MAX_KEEP=5.

transcribe.py

Speech → timestamps

Lazy-loads WhisperX small. Aligns words when possible. Writes transcript.json and transcript.srt. Device: CUDA if present, otherwise CPU (MPS is avoided).

nominate.py

Broad search

ollama.chat(..., format="json") with prompts/nominate_clips.txt. Chunks long transcripts. Snaps times onto real segments. If fewer than 3 clips, sliding-window fallback.

rank.py

Topic check

Encodes each candidate against learning objectives with MiniLM. Score = max cosine similarity. Returns Top N for the review tab. Ranking is not the final cut.

cut.py

Internal cuts

cut_clip tries stream-copy, then re-encodes. make_preview always re-encodes for review playback. Raw files stay under work/{run}/raw_clips/.

assemble.py

One timeline

Intro card → normalized raw clips → takeaway/CTA end card. Caption cues are shifted onto the compilation clock and burned with Pillow overlays (this ffmpeg build has no drawtext / subtitles).

export.py

Ship the bundle

Orchestrates cut + assemble. Writes compilation.mp4, captions.srt, post.txt, selection.json, then zip. Refuses export unless 3–5 clips are kept.

package.py

Unused by export

Older per-clip packager (9:16, drawtext title/CTA). Current product path does not call it. Kept as leftover from the first MVP.

4. Data contracts

Candidate (nominate → rank → review)

FieldMeaning
idStable id after normalize, c1…cn
start / endSeconds on the source video, snapped to transcript sentences
title / takeaway / quote / reasonLLM (or window fallback) text
scoreAdded by rank.py, max cosine vs objectives
excerptTranscript slice covering the range

Human gate

Review judges topic fit, standalone completeness, and “one knowledge point”. A weak opening is not a reject — the user may edit start/end. Confirm copies kept rows into state["approved"] and unlocks Tab 4.

5. Assemble timeline

sequenceDiagram participant E as export.py participant C as cut.py participant A as assemble.py participant FF as ffmpeg participant P as Pillow E->>C: cut each kept range to work/raw_clips C->>FF: -ss start -to end E->>A: assemble_compilation(raws, takeaway, CTA) A->>P: intro PNG + end-card PNG A->>FF: turn cards into 1–2s / 2–5s silent videos A->>FF: normalize raw clips to one size/fps/audio A->>A: shift transcript cues by intro + prior clip durations A->>P: caption bar PNGs A->>FF: overlay captions in batches of 8 A-->>E: compilation.mp4 + captions.srt E->>E: post.txt + zip

Caption times: compilation_t = intro_duration + sum(previous clips) + (seg.start − clip.start). The source URL is never burned as a clickable link; it belongs in post.txt / the platform description.
