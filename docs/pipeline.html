Brevio Studio

How POC/ turns a long lecture into one compilation: WhisperX transcript, Ollama nomination, MiniLM rank, a human keep-gate of 3–5 clips, then ffmpeg assemble with burned captions.

1. Overview

The pipeline is text-first. Clips are found from a timestamped transcript, not by scanning pixels. Models only nominate and rank. A human must keep 3–5 on-topic clips before ffmpeg builds the file. The shipped artifact is one compilation (intro + clips + captions + takeaway/CTA), not separate shorts. The app does not auto-publish.

Design rules: find clips from text → human confirms → then cut. Topic fit beats social-media hook. Source URL lives in post.txt, never as a burned link.

2. Studio UI

Entry point: frontend/ (React) talking to api/main.py. Four stages share one saved run checkpoint (run_id, transcript, candidates, approved clips, aspect ratio, model). The API drives the shared callbacks in app.py through pipeline/workflow.py.

2. Clips Review the automatic selection, keep 1–5 clips, trim with Set in / Set out, then Generate preview (blueprint first). nominate_for_audience() → confirm_selection()

Aspect ratio is Original, 16:9, 9:16, or 1:1. Source video is letterboxed onto that canvas; it is not a center-crop 9:16 short.

utils.py

Shared I/O

Run folders, JSON/SRT, ffmpeg wrappers, canvas_size, snap_to_segments, excerpt by range. Constants: MAX_REVIEW=10, MIN_KEEP=3, MAX_KEEP=5.

transcribe.py

Speech → timestamps

WhisperX small, float32. CUDA if present, else CPU (MPS skipped). Word align when possible. Writes transcript.json / .srt.

nominate.py

Broad search

ollama.chat(..., format="json") with prompts/nominate_clips.txt. Chunks ~9000 chars, 2-sentence overlap. Sliding-window fallback if fewer than 3 clips.

rank.py

Topic check

MiniLM encodes each candidate vs learning objectives. Score = max cosine. Top 10 for review. Ranking is not the final cut.

cut.py

Internal cuts

make_preview always re-encodes. Export cuts also re-encode (copy=False) so start/end edits are accurate. Files stay under work/{run}/raw_clips/.

assemble.py

One timeline

Intro card → letterboxed clips → takeaway/CTA end card. Word cues shifted onto the compilation clock, burned as Pillow PNG overlays in batches of 8.

export.py

Ship the bundle

Orchestrates cut + assemble. Writes compilation.mp4, captions.srt, post.txt, selection.json, zip. Refuses unless 3–5 clips.

package.py

Unused leftover

Older per-clip packager (9:16 crop, drawtext). Current product path never calls it.

5. Nominate + rank

Teaching topic and learning objectives both go into the Ollama user prompt, so nomination is already topic-aware. Rank then scores those candidates against the objectives only. Topic is not re-encoded in MiniLM.

Why excerpt is needed

Title / takeaway / quote are short LLM strings and can miss wording that matches an objective. excerpt_for_range pulls the real WhisperX sentences inside [start, end] so the embedding sees what was actually said.

Chunk vs clip

A chunk is a prompt window (~9000 characters). A clip is an LLM-chosen time range that may span several sentences, possibly across the 2-sentence overlap. One chunk can yield several clips.

6. Human keep-gate

Review judges: on-topic? standalone? one knowledge point? A weak opening is not a reject — edit start/end instead. Confirm copies kept rows into state["approved"] and unlocks Tab 4.

Export rereads the live Review form. Last-minute End edits apply without clicking Confirm again. Human-edited times are not snapped back to sentence boundaries (that snap only runs during nomination).

Canvas

canvas_size() letterboxes onto the chosen ratio. For 9:16 the long side is at least 1920, so a typical lecture becomes 1080×1920 with pillarboxing, not a 360-px-wide card. Intro/end text wraps by pixel width, not a fixed character count.

8. Time-aligned captions

compilation_t = intro_duration
               + sum(previous clip durations)
               + (word.start − clip.start) × (norm_dur / source_dur)

Words inside the kept range are grouped until ~38 characters, ~3.2 seconds, or punctuation. If WhisperX alignment failed, whole sentences are used. Intro and end card have no cues. This ffmpeg build has no libass, so captions are PNG overlays, not the subtitles filter. Concat always re-encodes and overlays use -loop 1 so the first seconds are not blank.
