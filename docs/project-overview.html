03Implemented features

Understand

Audience-aware selection

General audience, beginners, students, professionals and advanced learners. Source concepts guide nomination without requiring a manually written teaching topic.

Inspect

Evidence-backed clip review

Preview clips, inspect timestamped quotes, edit boundaries and keep 1-5 excerpts. Context-risk candidates and redundant overlaps are filtered.

Compose

Automatic storyboard

Confirmation generates the opening, joins, synthesis and reflection question, then renders a preview. Claims, timing and text remain editable.

Present

Standalone narrated intro

A centered title on a full-screen dark green card with a gold accent. A synthetic voice reads only the title before original lecture speech begins.

Package

Multi-format captioned video

Original, landscape 16:9, portrait 9:16 and square 1:1 formats. Cuts, overlays or dividers connect clips; captions follow the measured timeline.

Govern

Revision-aware review

Named storyboard approval, non-overwriting exports, weighted final assessment and hash-based stale-review detection. Edits invalidate approval.

Quality boundary: model estimates and valid citations do not prove truth. Missing assessments remain unassessed rather than receiving invented passing scores.

04Architecture and deliverables

Modular Python pipeline

app.py orchestrates the UI. Modules in pipeline/ own transcription, nomination, editorial review, ranking, storyboard validation, cutting, assembly, export and assessment.

Intermediate data lives in work/. Final artifacts live in exports/RUN_ID/EXPORT_ID/. Each export is a new version.

The source URL is attribution text, not a download input. There is no automatic social publishing or authenticated approval service. Reviewer names are local declarations.

05Assessment: current vs. proposed

Implemented today

Human review, automatic calculation

The scorer validates evidence and calculates ratings. It does not independently watch, listen to or assess the video.

  • Source fidelity: 25%
  • Audience fit and learning value: 25%
  • Standalone coherence: 20%
  • Captions: 15%
  • Audio and visuals: 15%

Every dimension needs evidence and at least 3/4. Claims, context, caption readability and human final review must all pass. Incomplete reviews stay blocked.

Proposed / not implemented

Auto-assessment, one final human approval

Collect technical measurements and AI editorial estimates automatically, then present an evidence-backed report for final review.

  • Decoding, timing, caption and audio measurements.
  • Editorial comparison with surrounding source context.
  • Separate AI assessment and human approval records.
  • One final approval after watching and listening; unresolved checks still block approval.

Current behavior is different: storyboard approval and final assessment remain separate. Text-only AI cannot certify visual readability or listening quality.

06Run and verify

Local application

Requires Python, FFmpeg/ffprobe, a running Ollama service and its model; macOS Samantha for narrated openings.

pip install -r requirements.txt
ollama pull qwen2.5
python app.py

Regression coverage

Unit tests use controlled model responses. Media tests exercise encoding, narration and timing; they are not editorial certification.

python -m unittest discover -s tests -q

RUN_MEDIA_TESTS=1 python -m unittest discover -s tests -q
