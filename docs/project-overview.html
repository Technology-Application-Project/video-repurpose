Educational Short Clip Demo

Turn a lecture into a 30-60 second compilation for researchers, the general public or children, with automatically selected excerpts, local narration, captions and evidence-backed human review.

01From lecture to reviewed short

Gradio coordinates local transcription, nomination and automatic clip selection. Generation starts directly with the configured provider and request limits, without a separate cost-approval step. A human still reviews and approves the storyboard preview before export. Manual clip review remains available; automatic selection is not human approval.

03Image generation and video assembly

The active configuration is media_provider: local-illustration with Portkey text generation. The model describes a scene; local code draws card artwork. The final video combines original lecture excerpts with narrated cards, captions and music. B-roll generation and the inset overlay have been removed to keep attention on the educational content.

Images: evidence to PNG

  1. Build separate opening and ending briefs from the storyboard's cited excerpts and audience visual style.
  2. Ask the configured Gemini text model through Portkey for constrained scene JSON: colors, coordinates, opacity and layers of rectangles, ellipses, polygons and lines. The model does not supply executable code or markup.
  3. Validate colors and numbers, clamp coordinates, discard invalid shapes and require at least six usable shapes. Reject nearly blank results.
  4. Render with Pillow at double resolution, then downsample to 1280 × 720 or 720 × 1280. Save the PNG, source JSON, prompt, model identity and asset hash.

Text is overlaid by the card renderer, not painted by the model. Prompts request no real people, invented data, charts, results, logos or quotations; human review must still check meaning and suitability.

Video: assemble the lecture

  1. Keep the selected source excerpts and their original speech.
  2. Add narrated opening and ending cards using the generated artwork. Transition cards normally use a frame from the incoming source clip, with illustration fallback.
  3. Place captions on the measured timeline without adding a B-roll inset or illustration label over the lecture.
  4. Duck the music under speech and retain optional licensed sound effects. The audio-mixing step copies the assembled video stream without re-encoding its frames.

This is video editing and assembly, not generative video. Removing the former four-second overlay does not remove four seconds of footage or change the selected clip order.

Ownership: media.py builds evidence-linked briefs and mixes audio; cloud.py handles text/image/music requests, configuration, caching and the ledger; illustration.py validates scene data and renders local assets; cards.py lays out the narrated cards.

Controls and provenance: each batch allows at most four text requests, two image requests and one music request only when generated music is selected. Video requests are unsupported. Cached assets are reused and SHA-256 hashes are checked before rendering and export. Old drafts containing B-roll require regeneration and fresh preview approval; existing exports and assessment records are unchanged. Each generation reads current provider settings and creates a new batch; estimates are informational, not a consent gate. Card artwork is labelled conceptual illustration, not source evidence; a 1080p export does not make the 720p artwork native 1080p.

04Implemented features

Understand

Audience-aware selection

Researcher, General public and Kids (ages 8-12) have distinct wording, goals and voice presets. Automatic selection keeps up to three ranked, non-rejected excerpts within an estimated duration budget; manual selection allows 1-5.

Inspect

Evidence-backed clip review

Preview excerpts, inspect timestamped quotes and context risks, and edit boundaries. Complete-sentence fitting and overlap checks protect the selection; changed ranges need fresh editorial review.

Compose

Direct storyboard generation

Generate an audience-specific hook, bridges connecting adjacent excerpts, synthesis and an actionable CTA without a cost-approval checkbox. Request caps and a ledger constrain each batch. Measured narration must fit the 30-60 second compilation budget.

Present

Local audience voices

Researcher: Michael at 0.95x. General public: Heart at 1.0x. Kids: Sky at 0.98x with a +2-semitone pitch/formant effect, not a dedicated child voice. Missing local setup fails explicitly, with no silent Edge or system-voice fallback.

Package

Focused cards and captions

Renderer 2.0 gives intros and bridges whole-phrase reveals, compact text and localized shading. Bridges use the incoming source frame, with an illustration fallback. Generated media targets 16:9 and 9:16; Original and 1:1 currently resolve to 16:9 in this path.

Govern

Revision-aware review

Named preview approval, timestamped non-overwriting exports and artifact-bound assessments. Narration caches include provider, model, processing version, voice, speed and pitch. Export reuses approved audio; changed profiles, text or renderer settings require fresh review.

Quality boundary: model estimates and valid citations do not prove truth. Missing assessments remain unassessed rather than receiving invented passing scores.

05Architecture and deliverables

Modular Python pipeline

app.py orchestrates the UI. Modules in pipeline/ own transcription, nomination, editorial review, fitting, cloud requests, storyboard validation, narration, media, assembly, export and assessment. kokoro_tts.py isolates speech dependencies from the app runtime.

Intermediate data and cached narration live in work/. Final artifacts use exports/RUN_ID/YYYYMMDD-HHMMSS_audience_aspect_id/; exports/latest points to the newest export when supported. Older exports are never rewritten.

The source URL is attribution text, not a download input. There is no automatic social publishing or authenticated approval service. Reviewer names are local declarations. Old audience profiles require regeneration; existing exported files retain their original provenance.

06Assessment and current limits

Implemented today

Automatic technical checks

Objective assessment measures the exported artifact and reports failures first, with values, limits and suggested fixes. Matching artifact hashes and metric versions allow report reuse; changed files or policies require reassessment.

  • Decoding, streams, resolution and measured duration.
  • Caption timing, coverage and English reading speed: at most 17 characters/second for Kids, 20 for Researcher and General public; unknown audiences use a labelled conservative 17-CPS fallback. See the sourced caption policy.
  • Audio measurements, including separate narration-stem checks.
  • Recorded assets and narration provenance.

Missing evidence is unavailable, not a passing score. The automatic report explicitly leaves publication suitability not assessed; it does not certify factual accuracy, caption comprehension or subjective listening quality.

Separate human judgment

Evidence-backed final review

Named storyboard approval remains a pre-export gate. The separate human rubric records evidence, weighted ratings and publication gates after export.

  • Source fidelity: 25%
  • Audience fit and learning value: 25%
  • Standalone coherence: 20%
  • Captions: 15%
  • Audio and visuals: 15%

Every dimension needs evidence and at least 3/4. Claims, context, caption readability and human final review must all pass. Automatic clip selection and automated test exports are not human approval.

Validation snapshot, 15 October 2026: fresh end-to-end runs completed for all three audiences, producing 1080p landscape videos of 45.6, 42.8 and 37.6 seconds. Each passed 14 technical checks and failed caption reading speed on original lecture excerpts, not Kokoro narration. Seven older renderer-test assertions also remain failing in the current regression suite. Human listening, factual review and transition pacing still need review; technical completion is not publication readiness.

07Run and verify

Application and speech runtime

Requires Python, FFmpeg/ffprobe, Ollama, and uv for the isolated Kokoro environment. Run from the project root:

pip install -r requirements.txt
ollama pull qwen2.5

uv venv --python 3.12 --seed work/kokoro-runtime/.venv
uv pip install --python work/kokoro-runtime/.venv/bin/python \
  -r requirements-kokoro.txt
work/kokoro-runtime/.venv/bin/python pipeline/kokoro_tts.py --prepare

python app.py

The preparation step downloads the English model, Kokoro weights and voice packs once. Normal synthesis is offline. KOKORO_PYTHON and KOKORO_MODEL_CACHE can override the default runtime and cache paths.

Configure the cloud provider and reviewed pricing using the setup guide before generating a storyboard. Credentials belong in the private environment or ignored .env, never in source or exported artifacts. Local-illustration mode still makes paid cloud text calls; generation starts without a separate cost confirmation.

Regression coverage

Unit tests use controlled model responses. Media tests exercise encoding, narration and timing; they are not editorial certification.

python -m unittest discover -s tests -q
